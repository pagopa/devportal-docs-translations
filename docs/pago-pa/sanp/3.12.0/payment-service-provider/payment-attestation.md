# Payment Attestation

The physical copies produced by the PSP for a payment must contain at least the following information:

- date and time of the transaction
- tax code of the EC (_fiscalCodePA_)
- name of the EC (_companyName_)
- unique payment identifier, unique identifier assigned by the EC (_creditorReferenceId_)
- identifier of the PSP (at least company name and tax code)
- unique payment number (_paymentToken_)
- transaction amount (_totalAmount_)
- payment description (_paymentDescription_)

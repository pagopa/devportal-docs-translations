# SRTP Service Integration

### Fundamental Objectives and Commercial Benefits of SRTP

SRTP (SEPA Request-To-Pay) is a messaging functionality standard from the European Payments Council (EPC) that allows a beneficiary to request the initiation of a payment from a debtor, [covering various scenarios](https://docs.italia.it/italia/icdp/icdp-pnd-servizi-docs/it/v1.0-giugno-2022/la-definizione-di-prodotti-e-servizi-digitali.html) (B2C, B2B, B2I).

The main benefits include an improved user experience and the promotion of digital payments, particularly instant ones. SRTP is not a new payment instrument, but a complementary tool that facilitates the process. Acting as a catalyst for the evolution of digital payments, SRTP reduces errors and improves cash flow management for Public Administrations.

For more information, [we refer you to the official EPC website](https://www.europeanpaymentscouncil.eu/what-we-do/other-schemes/sepa-request-pay).

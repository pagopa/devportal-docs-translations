# Integration with pagoPA POS Gateway

The pagoPA POS Gateway will be a technological component made available by the pagoPA platform to simplify and standardize the dialogue between the management system used by the Creditor Entity and the physical POS terminal. This component will reduce the implementation complexity for the Creditor Entity, while ensuring that local collection is natively integrated with the payment, transfer, and reporting flows of the pagoPA node.

The following sections illustrate the integration methods with the pagoPA POS Gateway for CEs and PSPs, aimed at managing payments via a physical POS installed on the Creditor Entity's premises:

- [CE integration methods](EC-Integration-Method.md)
- [PSP integration methods](PSP-Integration-Method.md)

# Event Log

The function of the Event Log is to enable the traceability of every payment transaction activated on the pagoPA platform.

The payment transaction is carried out through application cooperation between different systems of the ECs, the pagoPA platform, and the PSPs. To reconstruct the entire process, it is necessary for each of the systems involved in the electronic payment to be equipped with specific functions to record the main steps of the payment transaction processing.

The traces recorded by the individual systems, in case of a verification request, must be extracted and compared with similar information produced by all collaborative systems involved in the operations concerned.

For comparison purposes, two areas for identifying the payment transaction have been established:

- the identification of the electronic payment, based on key fields that make the reference to the payment unique;
- the identification of the interface message exchange, based on the parameters of the messages themselves that unequivocally link such messages to the specific payment.

The operations entered in the Event Log must be kept for at least _24 months_.

The following table indicates the information and data representation specifications that all parties are required to provide for the verifications mentioned above.

| Data                             | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| eventDateTime                    | <p>Indicates the date and time of the event according to the ISO 8601 format, at millisecond resolution and always referred to GMT.<br>Format [YYYY]-[MM]-[DD]T[hh]:[mm]:[ss.sss]</p>                                                                                                                                                                                                                                                                            |
| domainIdentifier                 | Alphanumeric field containing the tax code of the EC                                                                                                                                                                                                                                                                                                                                                                                                             |
| uniquePaymentIdentifier          | Unique reference assigned to the payment by the EC.                                                                                                                                                                                                                                                                                                                                                                                              |
| paymentContextCode               | Unique code necessary to define the context in which the payment is made.                                                                                                                                                                                                                                                                                                                                                                        |
| noticeNumber                     | Number of the notice issued by the EC.                                                                                                                                                                                                                                                                                                                                                                                                           |
| paymentServiceProviderIdentifier | Identifier of the PSP, unique in the domain chosen by the end user and/or the EC.                                                                                                                                                                                                                                                                                                                                                                |
| paymentType                      | Technical form of payment present in the message that originated the event.                                                                                                                                                                                                                                                                                                                                                                      |
| component                        | System or subsystem that generated the event (e.g., FESP, WFESP).                                                                                                                                                                                                                                                                                                                             |
| eventCategory                    | INTERNAL/INTERFACE, indicates whether the traced event relates to an interface operation with other systems or represents an internal operation (e.g., status change) to its own system.                                                                                                                                                                                                      |
| eventType                        | Identifier of the event type. In the case of SOAP interactions, it is the name of the SOAP method.                                                                                                                                                                                                                                                                                                                               |
| eventSubtype                     | In the case of synchronous SOAP interactions, it takes the values REQ/RESP to indicate SOAP Request and SOAP Response, respectively.                                                                                                                                                                                                                                                                                                             |
| requesterIdentifier              | <p>In the case of INTERFACE-type events, the identifier of the requesting party's system within the domain must be used<br>(e.g., NodoDeiPagamentiSPC in the case of paGetPayment).<br>In the case of INTERNAL type events, a component or subcomponent name that generates the event can be used.</p>                                                                                                                                                           |
| responderIdentifier              | <p>In the case of INTERFACE-type events, the identifier of the responding party's system within the domain must be used<br>(e.g., identificativoStazioneIntermediarioPA in the case of paGetPayment).<br>In the case of INTERNAL type events, a component or subcomponent name that processes the event can be used. For the latter type, the value can coincide with the identificativoFruitore if there is no component that responds to the event itself.</p> |
| paIntermediaryStationIdentifier  | Identifier of the EC's intermediary Station in the pagoPA platform system, through which payment and receipt have transited.                                                                                                                                                                                                                                                                                                                     |
| paymentChannel                   | Identifier of the PSP's Channel in the pagoPA platform system through which payment and receipt have passed.                                                                                                                                                                                                                                                                                                                                     |
| interfaceSpecificParameters      | Specific parameters used in the interface by the PSP or the EC.                                                                                                                                                                                                                                                                                                                                                                                  |
| outcome                          | <p>Optional field depending on the status of the operation at the time the event is recorded.<br>Mandatory in the case of SOAP requests.</p>                                                                                                                                                                                                                                                                                                                     |

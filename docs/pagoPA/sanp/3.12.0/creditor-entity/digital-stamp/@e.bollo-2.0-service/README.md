# @e.bollo 2.0 Service

Discussions between the Italian Revenue Agency (ADE) and PagoPA have highlighted the need to study an advanced framework for managing the sale and use of Stamp Duties.

{% hint style="info" %}
All details related to the scenarios provided by the ADE referred to in this document are described within the official documentation, which can be downloaded [here](https://www.agenziaentrate.gov.it/portale/documents/20143/249463/Linee+guida+servizio+ebollo+per+scheda+-+citt_Ae.bollo_LineeGuida_release2.0_dic.18.pdf/57b3b3d5-2b7e-21cf-f77d-48498a344885?t=1551273230817).
{% endhint %}

The evolution of the @e.bollo service involves the implementation of the following scenario:

- **Scenario A - Payment Due** - Payment of stamp duty as part of online services from administrations that generate “Digital Documents”.

{% hint style="info" %}
The **@e.bollo 2.0** service does not replace the existing [@e.bollo Service](../@e.bollo-service); the scenario whose implementation is described in this document is to be considered a simplification that can be implemented at the discretion of the Creditor Entity (EC).
{% endhint %}

# Debt Positions

With the **debt positions** service, PagoPA aims to offer the technical management of debt positions to Technological Partners, Technological Intermediaries, and possibly directly to Creditor Bodies that need it. "Management" refers to both the component concerning the creation, updating, and deletion of Debt Positions—including those originating from **spontaneous payment** requests—and the component related to the payment of these positions through the Payments Hub.

In addition to updating the status of debt positions following interaction with the pagoPA platform for payment execution, the service provides functionalities to retrieve the reporting flows provided by PSPs.

Regarding **spontaneous payments**, functionalities are available for Technological Partners, Technological Intermediaries, and possibly directly for interested Creditor Bodies to subscribe to individual services.

Adherence to the service is voluntary. For the procedure, refer to the [_BackOffice-pagopa_](https://docs.pagopa.it/manuale-back-office-pagopa) manual, [API Key Generation](https://docs.pagopa.it/manuale-back-office-pagopa/manuale-operativo-back-office-pagopa-ente-creditore/funzionalita/generazione-api-key) section.

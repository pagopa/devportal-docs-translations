# Checkout

{% hint style="info" %}
For workflow details, see [checkout.md](../casi-duso/pagamento-da-touchpoint-pagopa/checkout.md "mention")
{% endhint %}

## What it is

pagoPA Checkout is a web app for desktop and mobile that allows users to make payments on the pagoPA platform using the data from the payment notice, without any user registration.

{% embed url="https://checkout.pagopa.it" %}
Link to the pagoPA Checkout website
{% endembed %}

## Key benefits

- No registration: the user only enters an email address to receive the payment outcome;
- compatible with the most widely used browsers in Italy on both desktop and mobile;
- for each payment, it is possible to select the most convenient PSP.

## Supported methods

The list of methods that allow payments through pagoPA Checkout is constantly being updated. The [interactive prototype](checkout.md#undefined) shows the various currently established flows.

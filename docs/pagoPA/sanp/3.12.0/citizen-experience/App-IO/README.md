## Compatible methods

The IO Wallet allows you to save different payment methods to more easily carry out various in-app operations without having to enter the data each time. If compatible, the methods can be used not only for in-app payments but also for other spending-related initiatives.

{% hint style="info" %}
You can change the preferences for each method at any time from the Wallet section.
{% endhint %}

## Main advantages

- By saving the various methods in the Wallet, you can reduce the number of steps to complete a payment;
- for each payment, you can select the most convenient PSP;
- payment outcomes are saved in one place.

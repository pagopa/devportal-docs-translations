# PayPal

## Adding PayPal account (Onboarding)

The following flow describes the user experience for adding a PayPal account to the IO app Wallet.

#### Key steps

1. The user selects a PSP (can be changed during each payment)
2. The user enters their PayPal credentials
3. The user performs two-factor authentication (e.g. in the PayPal app)
4. The user accepts the terms of use and authorises PayPal to authorise pagoPA transactions managed by the selected PSP
5. The user verifies the features associated with the added method

## Payment

The flow describes the payment experience in the IO app using the PayPal method.

{% hint style="info" %}
Payments with PayPal do not require second-factor authentication.
{% endhint %}

{% hint style="info" %}
You can also add this method during a payment in progress; what is described in [#aggiunta-dellaccount-paypal-onboarding](payPal.md#aggiunta-dellaccount-paypal-onboarding "mention") applies.
{% endhint %}

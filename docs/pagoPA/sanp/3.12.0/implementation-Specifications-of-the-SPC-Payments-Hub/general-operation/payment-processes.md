# Payment processes

The payment process can be initiated through the following channels

- EC's Frontend
- PSP's Touchpoint
- IO App <img src="../../.gitbook/assets/image (7).png" alt="" data-size="line">
- PagoPA S.p.A. Checkout

The following table shows the features available to users for each channel.

<table><thead><tr><th width="166"></th><th width="150" data-type="checkbox">EC Frontend</th><th width="150" data-type="checkbox">IO app</th><th width="150" data-type="checkbox">Checkout</th></tr></thead><tbody><tr><td>Wallet management</td><td>false</td><td>true</td><td>false</td></tr><tr><td>Card payments</td><td>true</td><td>true</td><td>true</td></tr><tr><td>Payment via bank account</td><td>true</td><td>false</td><td>true</td></tr><tr><td>Payment without registration</td><td>true</td><td>false</td><td>true</td></tr><tr><td>Payment via third-party app</td><td>true</td><td>true</td><td>true</td></tr><tr><td>PSP selection</td><td>true</td><td>true</td><td>true</td></tr></tbody></table>

The table does not include a specific column for the features available on PSP channels, since these features are not directly managed by PagoPA S.p.A. However, it should be noted that the following features could potentially be made available on PSP channels:

- wallet management
- card payments
- payment via bank account
- payment without registration.
